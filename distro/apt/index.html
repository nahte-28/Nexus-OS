Pakketbron van NEXUS OS

Hier haalt NEXUS OS zijn updates. Ondertekend met de sleutel van NEXUS OS.

Op NEXUS OS

Niets te doen: de bron staat er al, en NEXUS werkt zichzelf om de zes uur bij. Meteen bijwerken kan met:

sudo systemctl start nexus-os-update

Op Debian, Ubuntu of Mint

Voeg de bron toe en installeer NEXUS. Daarna komen updates vanzelf binnen, en ook met sudo apt upgrade.

curl -fsSLo /tmp/nexus-os-updates.deb https://nahte-28.github.io/Nexus-OS/apt/nexus-os-updates.deb
sudo apt install /tmp/nexus-os-updates.deb
sudo apt update
sudo apt install nexus-os

Voor wie het wil nakijken

Bron: deb [signed-by=/usr/share/keyrings/nexus-os.asc] https://nahte-28.github.io/Nexus-OS/apt stable main. Publieke sleutel: nexus-os.asc. Broncode: github.com/nahte-28/Nexus-OS.
